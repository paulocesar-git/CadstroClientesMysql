# CadstroClientesMysql
Sistema integrado C# e MySQL, atividade de Linguagem de Programação 1.

## Setup SQL 
1. Abrir o XAMPP e iniciar o servidor MySQL
2. Criar servidor localhost sem senha no MySQL Workbench
3. Executar o script SQL para gerar as tabelas

- Importante: alterar em `banco.cs` com a porta atual do XAMPP - no projeto encontra-se a porta `3308`

## Funcionalidades
- **Novo:** Limpa os campos para uma nova inclusão
- **Salvar:** Salva uma nova entrada
- **Excluir:** Exclui uma entrada selecionada
- **Buscar:** Busca uma entrada pelo nome digitado na "Busca por nome"
